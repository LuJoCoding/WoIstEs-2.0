# Test-Checkliste „Wo ist's?“ 2.0

Vor dem Test: App 1.0 mit ein paar Einträgen (inkl. Foto + Favoriten) **nicht löschen**, sondern 2.0 per Sideloadly darüber installieren.

## A. Update & alte Funktionen (müssen alle noch gehen)
- [ ] Nach dem Update sind alle Gegenstände, Fotos, Favoriten, Farben und die Sprache noch da.
- [ ] Suche findet Gegenstände nach Name und Ortsnotiz; leere Suche zeigt alle.
- [ ] 4 Favoriten-Kacheln; 5. Favorit → Hinweis „Favoriten voll“.
- [ ] „Zuletzt verwendet“ zeigt die letzten 4 mit „vor … Min/Std“.
- [ ] Plus → Foto: Kamera, „Wiederholen“/„Foto benutzen“, Foto klein oben, Name, Fertig. Foto ist **nicht** in der Fotos-App.
- [ ] Plus → Foto → „Neu aufnehmen“ → Abbrechen: altes Foto bleibt.
- [ ] Plus → Notiz: ohne Name/Ort ist „Fertig“ ausgegraut.
- [ ] Bestehenden Gegenstand unter dem Namensfeld antippen → Hinweis „Alter Ort wird ersetzt“ → speichern → alter Ort/Foto weg, nur ein Eintrag.
- [ ] Gleicher Name in anderer Schreibweise („schlüssel“) → ebenfalls Überschreiben.
- [ ] Detailansicht: Foto groß (Zoom), Wo, Wann, Favorit an/aus, Name & Symbol ändern (Doppelname blockiert), Löschen.
- [ ] Einstellungen: Sprache, 6 Vorlagen, 4 eigene Farben (Text bleibt lesbar), Standardfarben, „Symbole statt Namen“, Alle Einträge löschen.
- [ ] Kamera verweigert → Hinweis mit „Einstellungen öffnen“.

## B. Orte & Räume
- [ ] Beim ersten Start von 2.0 gibt es Küche, Wohnzimmer, Schlafzimmer, Flur, Büro, Auto, Rucksack.
- [ ] Eintrag: Chips „Wo?“ antippen/abwählen, „+ Neuer Ort“ legt an und wählt direkt aus.
- [ ] Notiz-Eintrag: nur Ort (ohne Text) reicht zum Speichern.
- [ ] Favoriten-Kachel und „Zuletzt verwendet“ zeigen den Ort; Detailansicht → Ort antippen → Liste „Was liegt hier?“ → Gegenstand antippen wechselt zu dessen Detail.
- [ ] Suche: Filter-Chips „Alle | Küche | …“ (nur Orte mit Gegenständen); Suche nach Ortsname findet Gegenstände.
- [ ] Einstellungen → Orte: Umbenennen, Symbol, eigene Farbe, Bearbeiten → Sortieren, Wischen → Löschen (Gegenstände bleiben, verlieren Ort), Alle Orte löschen.
- [ ] „Orte verwenden“ aus → keine Chips/Orte sichtbar, App wie 1.0; wieder an → Orte sind noch da.

## C. Siri & Kurzbefehle
- [ ] „Hey Siri, wo ist mein Schlüssel in Wo ist's?“ → Antwort mit Ort + Zeit + Kärtchen.
- [ ] „Hey Siri, Schlüssel liegt woanders in Wo ist's?“ → Siri fragt nach dem Ort → gespeichert, alter Ort ersetzt (in der App prüfen).
- [ ] „Hey Siri, was liegt im Auto in Wo ist's?“ → Liste.
- [ ] „Hey Siri, neuer Eintrag in Wo ist's?“ → App öffnet direkt die Kamera.
- [ ] Englisch: „Where are my keys in Wo ist's?“.
- [ ] Kurzbefehle-App: „Ort speichern (Name)“ mit neuem Namen legt neuen Gegenstand an.
- [ ] „Orte auch bei gesperrtem iPhone vorlesen“ aus → Siri verlangt Entsperren.

## D. Widgets
- [ ] Homescreen klein: Favorit wählbar (gedrückt halten → Widget bearbeiten), zeigt Name/Symbol, Ort, Zeit, Foto als Hintergrund; antippen öffnet Detail.
- [ ] Mittel: 2×2 Favoriten in deinen Farben; leere Kachel → öffnet Plus-Menü.
- [ ] Groß: Favoriten + Zuletzt verwendet + „+ Eintrag“-Knopf.
- [ ] Sperrbildschirm: rund (Symbol), rechteckig (Name + Ort), Inline.
- [ ] Nach Farbwechsel/Speichern aktualisiert sich das Widget.
- [ ] Einstellungen → Widget: Fotos aus / Ort aus / Datenschutz-Modus (Ort nur entsperrt sichtbar).
- [ ] Falls „Öffne Wo ist's?, um das Widget zu aktivieren“: einmal App öffnen; bleibt der Text, fehlt die App Group (siehe README).

## E. Erinnerungen
- [ ] Einschalten → iOS fragt nach Mitteilungen; ablehnen → Hinweis + „Einstellungen öffnen“.
- [ ] Detailansicht → Erinnerung → Zeit in 2 Minuten → Mitteilung kommt mit Name + Ort.
- [ ] Mitteilung lange drücken → „Ja, liegt noch da“ (Zeit in der App springt auf „gerade eben“), „Neuer Ort“ (Formular öffnet mit Gegenstand), „Öffnen“ (Detail).
- [ ] Wiederholen täglich/wöchentlich/monatlich einstellbar; „Erinnerung entfernen“.
- [ ] „Liegt es noch da?“: Intervall 1 Woche … 1 Jahr, nur Favoriten/alle, Ruhezeit (Mitteilung außerhalb wird verschoben).
- [ ] App-Sperre an → Mitteilungstext ohne Ort („Erinnerung zu: …“).
- [ ] Erinnerungen aus → keine Mitteilungen mehr.

## F. App-Sperre
- [ ] Einschalten verlangt Face ID/Code; ohne Gerätecode ist der Schalter aus mit Erklärung.
- [ ] „Sofort“: App in Hintergrund → zurück → Sperrbildschirm, Face ID automatisch; abbrechen → „Entsperren“-Knopf.
- [ ] Sperre liegt auch über offenen Sheets/Detailansicht/Foto-Vollbild.
- [ ] 1/5/15 Minuten: innerhalb der Zeit keine Sperre, danach schon.
- [ ] App-Umschalter zeigt nur Hintergrundfarbe (Inhalt verbergen an).
- [ ] Widget/Mitteilung antippen bei gesperrter App → erst entsperren, dann öffnet sich das Ziel.

## G. Animationen & Anzeige
- [ ] Start: Kacheln/Zeilen blenden gestaffelt ein (nur einmal).
- [ ] Plus dreht sich zum ×, Optionen erscheinen gestaffelt; Fertig → Häkchen → Eintrag gleitet nach oben.
- [ ] Farbwechsel in den Einstellungen blendet weich; alle 6 Vorlagen + sehr helle/dunkle eigene Farben lesbar.
- [ ] Haptik aus → kein Vibrieren; „Animationen reduzieren“ (App oder iOS) → nur Überblendungen.
- [ ] Große Schrift (Einstellungen → Anzeige → Textgröße) → nichts abgeschnitten.
